there you can see 
PORTS
3306/tcp, 33060/tcp

but its not your system port you can't access 3306 from your system directly
there we use port binding where a system port redirect our request to this container










to do that use 
docker run -p<your_system_port>:<conatiner_define_port> <image_name>

example:- docker run -e MYSQL_ROOT_PASSWORD=secret -p5000:3306 mysql (now we can access it throw 5000 in my system)
